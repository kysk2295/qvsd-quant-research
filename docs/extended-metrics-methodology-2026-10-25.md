# NQ 전략 확장 평가지표와 재평가 방법

2026-10-25에 공개 자료를 확인하고 기존 네이티브 거래 원장을 재평가했다. 새 전략 실행이나 미래 데이터 손익 열람은 없다. 지표를 추가한 시점은 과거 결과를 이미 본 이후이므로 사전 등록된 새 검정으로 주장하지 않는다. 결과에 맞춰 진입·청산·선정·미래 계획을 바꾸지 않는다.

## 조사 근거

- [CME: The Mathematics of Trading Success](https://www.cmegroup.com/education/courses/trading-psychology/the-mathematics-of-trading-success): 승률뿐 아니라 이익과 손실의 크기를 결합해야 한다. 여기서는 실현 손익비와 비용 후 거래당 평균 손익을 함께 계산한다.
- [NinjaTrader: Statistics Definitions](https://static.ninjatrader.com/support/helpGuides/nt8/statistics_definitions.htm): 거래통계·낙폭·MAE/MFE·청산 효율의 정의를 확인했다. 백테스트 MAE/MFE는 봉의 고가/저가를 사용할 수 있다. 네이티브 월간 Sharpe/Sortino는 표본이 한 달 이하이면 1을 반환할 수 있으므로 이번 평가에서는 그 기본값을 우수 성과로 읽지 않는다.
- [Andrew Lo: The Statistics of Sharpe Ratios](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=377260): 추정오차와 자기상관 때문에 단순 제곱근 연율화가 일반적으로 성립하지 않는다. 이번 일별 지표는 연율화하지 않는다.
- [Bailey & López de Prado: The Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf): 다중 시도·선택 편향·비정규성을 함께 고려해야 한다. 보존된 206개 기록은 독립 실험 206개가 아니며 전체 비교 가능한 수익률 패널과 유효 독립 시도 수가 없으므로 DSR/PBO 값을 만들어내지 않는다.

## 계산 패널

| 관점 | 계산 | 해석 |
|---|---|---|
| 승패 | 비용 후 승률, 승·패·본전 수 | 승률 하나로 우열 판단 금지 |
| 손익 구조 | 평균 이익 / 평균 손실 절댓값 = 실현 손익비; 총 양의 순손익 / 총 음의 순손익 절댓값 = PF | 목표 손익비와 실제 달성 손익비를 구분 |
| 기대값 | 순손익 합 / 거래 수 = 승률×평균 이익 − 패배율×평균 손실 | 미래 기대수익 보장이 아닌 표본 평균 |
| 손익분기 | 이익·손실이 모두 있으면 1/(1+실현 손익비) | 본전 제외 조건부 승률 기준; 분포가 유지된다는 가정 |
| 위험 | 거래 청산 DD, 일 마감 DD, 연속 손실, 최악 거래/일, 회복되지 않은 낙폭 기간 | 보유 중 DD와 별도; 볼린저는 기존 Last 경로 범위 추가 |
| 빈도 | 무거래일 포함 일평균 거래, 활동일, 하루 4회 이상 비율 | 대회 라운드 최소 진입 규정의 충족 여부와 다름 |
| 집중도 | 최고 수익일·상위 3일 제외 손익, 양의 일손익 중 최고일 비중 | 소수 대박에 의존하는지 확인 |
| 비용 | 추가 편도 0/1/2/4틱 가정, 손익분기 추가틱 | 원래 체결을 고정한 산술 민감도; 재체결 시뮬레이션 아님 |
| 타점·청산 진단 | 평균 MAE/MFE, 최대 유리 움직임에서 돌려준 금액, 방향을 맞춘 구간 내 진입/청산 효율 | 봉 기반·실제 보유기간 조건부 진단이며 미래를 예측한 타점 능력의 증명 아님 |
| 시간·방향 | 보유시간, 진입 시간대·롱/숏별 손익, 청산 주문명 | 같은 표본의 사후 분해; 유리한 시간대로 재최적화하지 않음 |
| 위험조정 | 비연율 일별 Sharpe, MAR0 Sortino | 고정 시작자본 $150,000으로 나눈 일손익; 짧은 표본의 기술통계 |
| 불확실성 | 3세션 순환 블록, 2,000회 고정 시드 재표집의 일평균 손익 2.5–97.5백분위 | 10세션 이상일 때만 탐색용 표시; 정상성/블록 길이/다중선택 미보정 |

PF에서 이기는 거래/지는 거래는 외부 수수료를 차감한 뒤 분류한다. 네이티브의 gross/points 기준 분류와 다를 수 있다. 손실이 한 번도 없으면 PF와 손익비는 미정의로 남긴다. 1전 1승을 무한 PF로 순위화하지 않는다. 0거래는 승률 0%가 아니라 계산 불가다.

일별 Sharpe = mean(daily PnL/150000) / sample SD(daily PnL/150000). Sortino는 같은 평균을 sqrt(mean(min(return,0)^2))로 나눈다. 무위험수익/MAR=0이라는 기술적 가정이며 NinjaTrader 월간 수식과 다른 값이다. 관측 최하위 10% 일손익 평균도 1~2일 수준일 수 있어 미래 CVaR로 해석하지 않는다. 연율 수익·Calmar·전략 간 포트폴리오 최적화는 보고하지 않는다.

48틱이 실제 명세인 후보에 한해서 순손익을 초기 명목 위험 $240×계약 수로 나눈 R을 계산했다. 가변 손절인데 초기 손절 가격이 원장에 없는 Cafe 등은 R을 계산하지 않았다. 고정 48틱 자체의 타당성은 별도 미검증 사항이다.

구간 효율은 유리 방향 좌표에서 계산한다: 진입 효율=MFE/(MFE+MAE), 청산 효율=(gross PnL+MAE)/(MFE+MAE). 분모가 0이면 제외하고 MAE/MFE가 실현 이동을 포함하지 못하면 불일치로 분리한다. MFE−gross PnL은 비용 전 되돌림 금액이다. 정확한 체결 시점 이후 고정 1/5/10분 markout, 첫 목표/손절 도달 순서, 호가로 청산 가능한 이익은 별도 틱·호가 감사 없이는 확인된 것으로 취급하지 않는다. 높은 MFE를 보고 사후 최적 익절을 정하지 않는다.

## 데이터와 중복 처리

현재 보존된 주요 12개 구성×2비용 조건=24개 점수표를 만든다. 각 후보는 자기 검증 기간만 사용한다. 서로 기간이 다르므로 순위표로 해석하지 않는다. RSI는 수정 완료 원장과 거래 없는 3일 연장만 사용한다. OFI는 날짜가 겹치지 않는 5구간을 합친다. NR7은 원래 거래 없는 8일과 7일 연장 원장을 합치며, 원래 구간의 고비용 조건은 0거래 원장의 단순 재가격일 뿐 추가 실험이 아니다.

Cafe는 High Tick1의 세 구성만 사용하고 Standard 중복을 제외한다. 저장된 무거래 연장 결과와 커버리지 증거로 0거래일을 포함한다. 수정 전 RSI, 채널 길이 선택에 쓰인 개발 대안, 원전과 다른 옛 프록시/Doji/ORB 및 로깅 진단 중복은 이번 비교 표에서 제외하고 기존 기록을 유지한다. 시도 이력을 지우거나 이 표를 독립 OOS라고 부르지 않는다.

기존 실행 상태·원장·전략 코드·미래 계획은 변경하지 않는다. 모든 입력 파일 해시, 합산 구성 run ID, 계산기 테스트 근거를 `research/extended-metrics-review.json`에 기록한다. 대시보드에는 기존 숫자를 덮어쓰지 않고 **후보/비용별 합산 평가**라는 별도 항목으로 게시한다. 한 구간의 결과에 붙은 합산 값은 그 구간 단독 성과가 아니다.

## 판단 원칙

단일 합성 점수나 승률/PF 목표를 새로 만들어 채택하지 않는다. 구현·데이터 검증, 비용 후 경제성, 손실 경로, 집중도, 표본·독립성, 실행 가능성을 각각 확인한다. 이번 기술적 요약의 ‘10거래 미만’ 표시는 희소성을 알리는 편의 표시이지 보편적인 최소 표본 기준이나 통계적 합격선이 아니다. 미래 볼린저의 사전 등록된 비용·집중도 조건 및 판정일은 그대로다.
