# NQ 고정 미래 검증 실행 경로

**검증된 전략은 아직 없다. 고정 후보의 자료 확인 → 한 번 제출 → 같은 실행 결과 저장 → 판독 경로를 연결했다. 실제 미래 백테스트와 체결 검증은 미실행이다.**

최종 합성 검사 81개가 통과했다. 이번 준비 단계에서 실제 시장 파일 읽기, NinjaTrader 호출, 다운로드, import 및 백테스트는 모두 0회다. 이 숫자는 이번 작업의 범위이며 이전 역사 백테스트까지 없었다는 뜻은 아니다.

## 구현한 범위

- 실제 시각·고정 계획·실행 중단/불명확 상태를 먼저 확인한다. 판정 시각 전에는 자료를 읽거나 NinjaTrader를 호출하지 않는다.
- 10세션 각각의 기존 품질 검사, 원본·변환본·추출본 해시, 대시보드 ACK, 가져오기 완료 기록을 대조한다. 판독에는 정규장 전후 문맥을 포함한 원본 Last 자료를 사용한다.
- 실제 실행 시 설치 전략과 검토한 백엔드 소스, 실행 엔진, 저장된 시간대 기대값, 캐시 파일, 작업 상태를 확인한다. 제출 직전 작업과 import 상태를 다시 읽는다.
- 고정된 요청·자료·엔진에 묶인 예약과 제출 의도를 디스크에 먼저 기록한다. 한 번의 제출 이후 응답이 불명확해도 다시 제출하지 않는다. 일반 제출 경로는 계속 차단하며, 실제 운영 경로에는 시험용 미래 시각을 넣을 수 없다.
- 동일한 실행 ID만 조회하고 원결과를 보존한다. 이후 기존 판독기가 10세션의 봉·신호·시각·거래 원장·비용 및 Last 가격 경로를 검사한다. 이 코드에는 주문·Playback·권한 활성화·재컴파일 경로가 없다.

## 검사 결과와 한계

등록한 합성 검사 최대 5회 중 2회를 사용했다. 첫 76개 검사에서는 기존 실행 생명주기 검사의 임시 상태 파일 교체가 Windows `WinError 5`로 실패했다. 실패 기록을 보존했으며 원인을 확정하거나 해결했다고 주장하지 않는다. 검토에서 발견한 제출 경로 노출, 시각 재검사, 상태 최신성, 백엔드 해시 고정과 동시 실행 문제를 보완한 최종 81개 검사는 모두 통과했다. 이는 합성 자료와 가짜 네이티브 응답에 대한 코드 검사다.

2026-10-25 13:10:55 UTC에 실제 시각으로 준비 검사를 한 번 실행했다. `Prospective decision time has not arrived`로 중단됐으며 자료 로더·네이티브 호출·실행 예약은 모두 0회였다. 10개 날짜 모두 아직 세션 종료 전이고 다운로드 파일이 없다는 메타데이터를 기록했다. 현재 진행 중인 네이티브 검증 작업은 없다.

설치 소스·전략 목록·DLL 시각은 실무적인 확인 자료지만 실행 메서드와 소스의 완전한 동등성 증명은 아니다. 이번 연결 코드가 실제 운영 데이터에서 동작했다는 증거도 아직 없다. 캐시 파일 존재·해시와 import의 done 상태만으로 봉 내용의 일치를 인정하지 않는다. 실제 실행 후 BAR·CLOCK·거래 원장을 대조해야 한다.

저장된 NinjaTrader 시간대 항목은 비어 있어 Windows의 `Korea Standard Time`을 기대값으로 기록한다. 이것을 실제 실행 시간대의 확정 증거로 쓰지 않으며 결과의 시간대·시각 기록과 다르면 검증을 보류한다. 작업 상태 조회도 모든 상태가 원자적으로 고정됐다는 증명은 아니다. 상태 파일 저장 오류, 불명확한 제출, 결과 누락은 성공으로 바꾸거나 재제출하지 않는다.

청산 주문의 인과관계, 실제 전략의 허용된 모의 체결, 더 긴 독립 기간 검증은 남아 있다. 10세션 검사를 통과하더라도 더 긴 검증 후보까지이며 Goal 완료가 아니다.

## 외부 조건 대기

동일한 미래 자료 부재는 연속된 세 작업에서 확인됐다.

| 작업 | 기록 | 확인한 조건 |
|---|---|---|
| 설치·실행 준비 점검 | `e8c8dbb` / deployment-readiness-result.json | 고정 10세션 미종료, 판정 시각 미도래 |
| 날짜별 가져오기 연결 | `206f18b` / future-import-preparation-result.json | 모든 날짜 awaiting_session_close |
| 이번 실행 경로 연결 | production-executor-dry-run.json | 실제 시각에서 자료·네이티브 접근 전 차단 |

현재 필요한 구현을 마쳤으므로 같은 준비 작업이나 기존 자료 최적화를 반복하지 않는다. Goal은 완료가 아니라 외부 조건 대기인 `blocked`로 기록한다. 첫 세션 종료는 **10월 27일 05:00 KST**, 고정 10세션의 판정은 **11월 7일 10:00 KST 이후**다. 날짜가 도래해도 원자료 수집·품질·가져오기·실행 조건이 충족돼야 한다. 취소된 30분 자동화나 새 예약 실행은 만들지 않았다.

세션 종료 후 기존 유한 수집·품질 검사·ACK·import가 끝나면, 판정 시각 이후 다음 명령들이 고정 계획에 따라 사용될 수 있다. 현재 이 명령들로 실제 제출하지 않았다.

```powershell
python -m runner.prospective_executor prepare
python -m runner.prospective_executor submit
python -m runner.prospective_executor observe
python -m runner.prospective_executor assess
```

`submit`은 다시 준비를 확인하고 단 한 번의 예약을 소비한다. `observe`는 같은 실행을 조회할 뿐이다. unknown 또는 오류 기록을 삭제해서 재시도하지 않는다. 기존 후보·기간·비용·최대 실험 횟수는 변경하지 않았다. 이 일정은 별도로 저장된 대회 제출 마감 전 검증 완료를 뜻하지 않는다.
