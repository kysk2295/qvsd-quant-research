# 연구 기록

## 2026-10-24 — 초기 분석 기준 버전

- 카페 48개 글 목록, 45개 글의 본문 텍스트 확인. 26·52·54번 본문과 첨부 영상·PDF·이미지의 검토가 남아 있음.
- OR 돌파, OR 리테스트, IB 실패돌파를 독립적인 실행 규칙으로 재구성.
- 두 종목과 두 비용 조건을 조합한 12개 시나리오 계산.
- 8개 체결·위험·미래 데이터 영향 관련 테스트 통과.
- 원시 데이터 해시와 보고서·결과 파일 확인.
- NQ IB 회귀는 전체 구간에서 우수했지만 최근 비용 스트레스에서 음수.
- GC 리테스트는 최근 양수이나 전체 수익이 소수 거래에 민감함.
- 단독 후보들의 거래 빈도가 낮아 최소 4회 진입 규정을 만족하기 어려울 수 있음.
- 실전 투입 승인 후보 없음. Windows 원자료 및 공식 시간·비용 대기.

## 2026-10-24 — Windows 원격 환경 재개

- 삭제된 windows-wol 스킬을 로컬 백업에서 복원하고 형식·셸 문법 검증 완료.
- WOL 요청 이후 Windows 원격 데스크톱 포트 및 Tailscale 응답 확인.
- Windows App에서 바탕화면과 NinjaTrader Control Center 화면 확인. 과거의 검은 화면은 이번 접속에서는 발생하지 않음.
- NinjaTrader가 요청한 8.1.8.3 → 8.1.8.4 필수 업데이트를 진행한 후 메인 화면 진입. 설치 후 버전 번호는 Help에서 별도 확인 필요.
- 원격 키보드 입력은 작동하지만 좌표 클릭 도구는 noWindowsAvailable 오류로 실패. 사용자에게 Tools → Historical Data 화면 열기를 요청.
- Control Center 연결 표시가 회색이고 계정 목록이 비어 있음. 저장 데이터의 존재·범위 및 데이터 제공사는 아직 확인하지 못함.
- 이번 단계에서 원자료 내보내기·새 백테스트·주문 실행은 수행하지 않음. 기존 예비 결과의 판단은 그대로 유지.
