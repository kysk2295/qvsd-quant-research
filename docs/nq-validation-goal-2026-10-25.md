# NQ 검증 전략 탐색 Goal

2026년 10월 25일 사용자의 “골 명령어를 사용해서 검증된 전략을 찾을 때까지 진행” 요청에 따라 Goal을 활성화했다. 목표는 NQ 전략이 사전에 정한 비용·손실·안정성 기준, NinjaTrader 백테스트, 독립 미사용 기간, 허용된 체결 검증을 통과하는 것이다. 이 문서는 Goal 시작 기록이며 전략 합격 선언이나 거래 실행 승인이 아니다.

## 시작 시점의 실제 결과

| 항목 | 상태 |
|---|---|
| 최근 시장 상태 | 15개 개발 세션의 최근 5일에서 변동폭·거래량 확대 관측 |
| 방향 지속 가설 | 등록한 일관성 기준 미충족, 60개 관측 중 방향 일치 28개; 거래 승률 아님 |
| 변동 규모 지속 가설 | 전체 예측오차 개선, 최근 5일 악화; 일관성 기준 미충족 |
| 10월 23일 원자료 | 가격·거래량·건수 불일치, 원인 미확정, 사용 제외 유지 |
| 기존 전략 | 여러 구성의 NinjaTrader 역사 백테스트는 존재하지만 채택 전략 없음 |
| 독립 검증 | 완료한 독립 OOS 날짜 0개 |
| 실제 전략 Replay·실시간 모의운용 | 미완료; 차단된 주문/Playback 경로 재시도 없음 |

## 완료 판정과 연구 순서

1. **데이터와 규칙을 고정한다.** 원자료 출처·누락·시각·거래 세션·계약을 확인하고, 가설·정확한 신호·진입·손절·청산·위험·비용·최대 실험 횟수·중단 조건을 결과 보기 전에 등록한다.
2. **구현을 확인한다.** 표본 신호와 NinjaScript가 같은 정보를 같은 시점에 사용하고, 실제 NinjaTrader 요청·실행 상태·거래 원장이 일치해야 한다. 지표 간 관계 연구를 전략 백테스트로 표시하지 않는다.
3. **비용·손실·불확실성을 평가한다.** 승률, 평균 이익/손실, 기대값, PF, 일별 수익, 최대 낙폭, 연속 손실, MAE/MFE, 보유 중 평가손실, 비용 민감도, 수익 집중도를 함께 본다. 미사용 기간의 기준과 표본 설계는 그 기간의 결과를 보기 전에 고정한다. 짧은 표본이나 넓은 불확실성은 보류로 남긴다.
4. **독립 검증과 체결 증거를 확보한다.** 고정 규칙의 미사용 기간 성과와 허용된 실제 전략 주문/체결 검증을 대조한다. 전략 Replay 또는 실시간 모의운용이 없으면 그 부분은 미완료다. 역사 백테스트를 실시간 전진 검증이라고 부르지 않는다.

이 네 단계와 해당 전략의 사전 판정 기준이 충족된 증거가 있어야 Goal 완료를 검토한다. 연구 결과는 조건과 검증 기간 안에서의 근거이며 미래 수익 보장이 아니다. 10세션의 양수 손익이나 높은 승률 한 가지로 완료하지 않는다.

다수 실험 중 좋은 결과만 선택하면 성과가 부풀려질 수 있으므로 실패와 탐색 횟수도 보존한다. DSR 등 선택 편향 보정은 필요한 수익 시계열·시도 수·의존성 가정이 갖춰질 때만 계산한다. 기존 짧은 표본에 확률 수치를 붙여 검증 완료로 만들지 않는다. 방법론 근거: [Bailey·López de Prado, The Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf).

NinjaTrader의 Tick Replay는 주문 체결 정확성을 보장하는 기능이 아니다. 고해상도 역사 체결과 실제 시간 흐름에서의 모의 체결은 별도 검증 대상이다. 근거: [Tick Replay 개발 문서](https://docs.ninjatrader.com/ninjascript/developing_for_tick_replay), [실시간과 백테스트 차이](https://static.ninjatrader.com/support/helpGuides/nt8/discrepancies_real-time_vs_bac.htm).

## 현재 예약과 다음 작업

기존 자료 역할 원장은 2026년 8월 14일~10월 23일을 보수적으로 개발 구간으로 처리한다. 아직 시험하지 않은 날짜 이름이나 복구한 파일이라는 이유로 이 구간을 독립 OOS로 바꾸지 않는다.

볼린저 1개 고정 후보의 10월 26일~11월 6일 10세션이 예약돼 있다. 판정일은 **11월 7일 10:00 KST**다. 계획은 높은 비용 및 추가 편도 4틱 민감도에서 양수, 최고 수익일 제외 후 양수 등을 더 긴 검증의 진입 기준으로 삼는다. 이것을 통과해도 기존 계획의 판정은 **더 긴 사전 등록 검증 후보**까지다. Goal 완료와 구분한다.

현재 실행 예산은 0회, 미래 조건부 예약은 1회다. Goal을 만들었다고 기존 게이트나 미사용 기간을 해제하지 않는다. 다른 후보로 교체하거나 같은 날짜에서 재최적화하지 않는다. 예약된 구간이 끝나면 정해진 실패/보류/후속 검증 분기로 진행하며, 새로운 연구는 새 근거·자료 역할·실험 한도를 먼저 기록한다.

바로 진행할 작업은 [제출 없는 검증 준비 패킷](../research/nq-goal-validation-readiness-plan.json)이다. 기존 사전 점검은 파일 존재를 보는 수준이므로, 각 날짜의 품질·원본/파생 해시·세션/DST·계획/코드 동일성·중복 실행·판정 시각을 확인하고 빠진 증거를 출력하도록 보완한다. 합성 자료로 검사를 확인하고 실제 메타데이터 초안 1회만 만든다. 이 단계에서 신규 다운로드·미래 가격 열람·성과 계산·native 제출은 0회다.

## 대회 준비와 구분할 사항

저장된 대회 요약의 제출 마감은 10월 29일 18시이고 미래 검증 판정일보다 빠르다. 따라서 11월 7일 판정을 대회 제출 전 검증 완료 일정으로 설명할 수 없다. 대회 공지의 최신 원문·세부 시간대·비용·종료 청산·진입 인정 규칙은 별도 확인이 필요하다. 공식 링크는 [QVSD 카페 공지](https://cafe.naver.com/f-e/cafes/31685329/articles/55)이며 이번 접근에서는 원문을 재확인하지 못했다. 저장된 요약과 현재 연구 가정을 구분한다.

실제 자금 주문·구매·차단된 경로 우회는 이 Goal의 작업이 아니다. 이전에 취소한 30분 자동화를 다시 만들지 않았다. Goal의 지속 연구와 예약 작업이 실제로 실행 중인지의 상태를 별도로 기록한다. 외부 자료나 실행 경로가 필요해 더 진행할 수 없는 시점에는 남은 조건을 명확히 보고한다.
